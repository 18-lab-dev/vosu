## OpenWiki

This repository uses OpenWiki for recurring code documentation. Start with `openwiki/quickstart.md`, then follow its links to architecture, workflows, domain concepts, operations, integrations, testing guidance, and source maps.

Run OpenWiki maintenance locally with the installed OpenWiki CLI and the maintainer’s local OpenAI/Codex subscription. Use the exact command `openwiki code --update --print`; do not restore or add a scheduled or manually dispatched OpenWiki GitHub Actions workflow. Do not hand-edit generated OpenWiki pages unless explicitly asked; prefer updating source code/docs and letting OpenWiki regenerate.
