# Removed interim edges (section 2 "Allowed workspace dependencies" notes);
# check-crate-boundaries.py rejects a normal, build or optional
# (feature-gated) edge from either crate to vosu-sys even if recorded here:
# - vosu-osu-reader -> vosu-sys: removed by M5 R1 (DC). Reads go through
#   `vosu_plugin_api::memory`/`PlanMemory`; every scan through an injected
#   `ScanBackend` (the host's SCAN_REQUEST path; no region-walk fallback);
#   the lazer executable root comes from the attach `path` fact; the offset
#   cache publishes/reads through `vosu_net::publish`; and the offset
#   generator's composer injects the gated `vosu_sys::process_spawn` spawn.
#   The `vosu-osu-reader -> vosu-sys` line below is a dev-dependency only:
#   unit tests compare against core's region walk and inject the real gate.
# - vosu-osu-state -> vosu-sys: removed by M5 R0. The reducer's read types
#   (`MemoryRead`, `ReadStatus`, `MemoryError`) now come from the
#   platform-neutral `vosu_plugin_api::memory`, which `vosu-sys` implements
#   (vosu-sys -> vosu-plugin-api) rather than defines.
# - vosu-osu-reader -> vosu-net: F7, DD/R5. The lazer offset generator
#   moved from the root crate into `vosu-osu-reader` and still needs
#   `vosu_net::{ZipLimits, extract_zip_atomic}` for hardened extraction of
#   its embedded bundle, and (M5 R1) `vosu_net::publish` for the atomic
#   offset-cache publish/read convention; not interim.
